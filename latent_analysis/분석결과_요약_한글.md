### 1. Error를 반영하는 거야?

**답변: 아니오 - TRM은 H-cycle 동안 에러를 보지 못합니다.**

**코드 분석 결과** (`step_by_step_inference_poc.py`, 186-194번째 줄):

```python
for h_step in range(max_h_steps):
    # L-cycles (저수준 정제)
    for l_step in range(model.config.L_cycles):
        z_L = inner.L_level(z_L, z_H + input_embeddings, **seq_info)

    # H-cycle 업데이트 (고수준 추론)
    z_H = inner.L_level(z_H, z_L, **seq_info)
```

**핵심 발견:**
- 모델은 `input_embeddings`(입력 그리드)만 받습니다
- 정답 레이블은 절대 H-cycle에 피드백되지 않음
- 각 반복은 오직 다음만 기반으로 개선됩니다:
  - 이전 잠재 상태 (z_H, z_L)
  - 입력 임베딩 (모든 H-step에서 동일)
  - 학습된 내부 동역학

**결론: 이것은 지도 에러 피드백이 아닌, 순수한 재귀적 자기 교정입니다.**

**의미:**
- 모델은 정답과 비교 없이 "맹목적으로" 자기 교정
- ARC 변환 규칙에 대한 학습된 사전 지식에 의존
- 수렴은 전적으로 내부 동역학에 달려있음

### 3. 916x512 차원에 대한 설명

**답변: [916 토큰, 512 hidden_dim]이 맞습니다 (500이 아님).**

**정확한 구조:**

```
전체 토큰 수: 916
├── Puzzle embedding: 16 토큰
│   └── 학습 가능한 태스크별 표현
└── Grid 토큰: 900 토큰 (30×30 그리드)
    └── 각 셀 = 1 토큰

토큰당 Hidden 차원: 512 (500 아님)
```

**Shape 세부사항:**
- `z_H`: [batch, 916, 512]
  - 916 토큰: 16 (퍼즐) + 900 (그리드)
  - 512: hidden state 차원
- `z_L`: [batch, 916, 512]
  - z_H와 같은 구조
  - 의미적 역할만 다름 (저수준 vs 고수준)

**질문 명확화:**
- "하나의 pixel을 500개의 hiddenstate로 표현" ❌
- "하나의 pixel을 512차원 벡터로 표현" ✓
- 각 그리드 셀 → 하나의 512차원 벡터

## 주요 발견사항

### 1. z_H와 z_L의 역할 차이

**z_H (고수준 추론)**:
- 태스크 수준의 추상화 담당
- 초기 H-step에서 큰 이동
- 변환 규칙 학습/적용

**z_L (저수준 정제)**:
- 그리드 수준의 세부사항 담당
- 점진적인 변화
- 셀별 예측 개선

**상호작용 패턴:**
- L-cycle: z_H 조건하에 z_L 정제
- H-cycle: z_L 기반으로 z_H 업데이트
- 계층적 반복 정제 과정

### 2. 수렴 패턴

**해결된 퍼즐의 특징:**
- H-step 2→3에서 작은 이동 (수렴)
- z_H와 z_L 궤적 안정화
- 일관된 예측 유지

**미해결 퍼즐의 특징:**
- 지속적으로 큰 이동 (발산)
- 불안정한 궤적
- 예측 계속 변화

### 아키텍처 이해

**TRM은 2개의 중첩 루프로 구성:**

```
각 H-cycle마다 (3번 반복):
    각 L-cycle마다 (6번 반복):
        z_L = L_level(z_L, z_H + input_embeddings)  # 저수준 정제
    z_H = L_level(z_H, z_L)  # 고수준 업데이트
```

**핵심 통찰:**
- L-cycle: 고수준 상태(z_H)를 조건으로 세부사항(z_L) 정제
- H-cycle: 정제된 세부사항(z_L) 기반으로 추상 추론(z_H) 업데이트
- 계층적 반복 정제 프로세스

1. **Puzzle embedding이 해결 가능성을 예측하는가?**
   - 임베딩 공간 위치와 성공률 상관관계
   - "쉬운 영역" vs "어려운 영역" 존재 여부

3. **Attention 패턴 시각화 가능한가?**
   - L_level transformer에서 attention weight 추출
   - 모델이 집중하는 그리드 영역 확인

4. **변환 유형별로 추론이 어떻게 다른가?**
   - 패턴 완성 vs 대칭 vs 색상 매핑
   - 다른 태스크가 다른 z_H/z_L 상호작용 패턴을 보이는가
